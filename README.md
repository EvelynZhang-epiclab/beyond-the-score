# Beyond the Score · Simple AI

Astra 能否成为机器人的“评审员”？机器人执行质量、任务进度与失败识别的研究博客。

- `index.html`：研究博客首页，正文依据 2026 年 10 月 14 日更新稿。
- `evidence.html`：原项目的交互结果、机器人回放和失败案例。
- `assets/figures/`：博客配图，保留原报告的数据与来源说明。
- `assets/Beyond-the-Score.pdf`：完整技术报告。

网站为静态 HTML/CSS/JavaScript，可直接通过 GitHub Pages 发布，无需构建或安装依赖。

本地预览：`python3 -m http.server 8000`，随后访问 `http://localhost:8000/`。
